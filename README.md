# 🤖 AI Career Advisor

An agentic AI web app that recommends a career path, learning roadmap, and hands-on project based on your skills and interests.

**SDG 8 — Decent Work & Economic Growth** | Solves the skill-job mismatch problem.

## Features
- 6 career paths: Python Dev, Web Dev, Data Analyst, AI/ML Engineer, Cybersecurity, DevOps
- AI Match Score (confidence %)
- Personalized learning roadmap
- Hands-on project suggestion
- PDF download of results

## Tech Stack
- Python, Flask, SQLite, HTML/CSS

## 🌐 Live Demo
👉 https://ai-career-advisor-p0hi.onrender.com

## Run Locally
```bash
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000
